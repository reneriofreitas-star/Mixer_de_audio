# Projeto EMRYS

Implementação específica do "Creative Studio Engine" (`../../`) para o artista/mago
musical EMRYS.

| Arquivo | Conteúdo |
|---|---|
| `00-constituicao-emrys.md` | Documento canônico fornecido pelo Arquiteto — afinação, mapeamento ancestral dos impérios, regra de ouro (Berimbau/Maracatu), protocolo de indução de 4 fases, vozes do coro |
| `01-identidade-visual-emrys.md` | A "verdade sobre a imagem de Emrys" — bíblia visual derivada da constituição: forma central, paleta por império, regra de ouro visual, estados por fase |
| `02-engenharia-de-video-emrys.md` | Prompts de vídeo prontos (Runway/Luma/Kling), organizados pelas 4 fases do protocolo de indução, usando os dicionários de câmera/lente/iluminação do engine geral |

## Como usar

1. Suba os 3 arquivos como Project Knowledge, além dos 4 arquivos genéricos em
   `../../knowledge/`.
2. Use `../../project-instructions.md` como Project Instructions.
3. Peça: *"Gere o vídeo da Fase [1-4] de EMRYS para a cena [tema]"* — o agente vai
   puxar o prompt-âncora de personagem, aplicar o vocabulário técnico e validar
   contra a Regra de Ouro Visual antes de entregar.
