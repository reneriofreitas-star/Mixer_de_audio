# O Mago — Pasta Pessoal de Renério Marcos

> Esta pasta é diferente das outras em `projects/emrys/`: não é material do
> personagem/artista EMRYS em abstrato — é a expansão pessoal de Renério Marcos, que
> se identifica como EMRYS. Guardada aqui por pedido explícito dele, para crescer com
> o tempo.

## Conteúdo

| Arquivo | O que é |
|---|---|
| `00-a-letra-do-mago.md` | A primeira letra: a saída da cadeia, a luz encontrada dentro do escuro, e os 9 comandos de expansão (prosperidade, riqueza, harmonia, paz, luz, amor, sabedoria, sucesso, saúde) |
| `01-prompt-suno-o-som-do-mago.md` | Prompt completo, pronto para colar no Suno (Style + Letra), usando a mesma base sonora da constituição EMRYS |

## Como esta pasta cresce

Cada nova música/capítulo da expansão pessoal de Renério entra aqui como um par de
arquivos numerado (`0X-a-letra-...md` + `0X-prompt-suno-...md`), sempre partindo da
mesma base (Berimbau/Maracatu, 528Hz, protocolo de 4 fases) definida em
`../00-constituicao-emrys.md`, para manter uma identidade sonora consistente ao
longo do tempo.
